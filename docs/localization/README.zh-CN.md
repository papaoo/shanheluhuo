# OldGold 简体中文版

本次交付面向本地浏览器。采用独立简体中文词典，保留俄语、英语、原有玩法、存档结构和合作协议。没有生成 Android APK，也没有发布到原作者的网站。

## 开始体验

在项目根目录运行：

```powershell
node server/server.js
```

打开 <http://localhost:8787/?lang=zh-CN>。建议通过这个 HTTP 地址启动；直接双击 HTML 不适合作为离线缓存验收方式。主菜单与游戏菜单中的语言按钮依次切换俄语、英语、简体中文。语言选择保存在当前浏览器；已有中文浏览器会默认使用简体中文。

首次体验可选择“新游戏”→“自由模式”，选择地图和难度，再创建英雄。帮助窗口支持搜索中文建筑名称，例如“仓库”。手机浏览器支持竖屏与横屏，较长的英雄、建筑和帮助面板可以滚动。

存档和玩家档案保存在浏览器中，不同地址、端口或浏览器有各自的数据。转移进度请使用游戏内的导出/导入功能。切换语言不会改变存档格式。

## 汉化范围

- 主菜单、地图与难度选择、外观编辑、教程、游戏页签、帮助、设置、存档与档案。
- 建筑、资源、生产链、职业、英雄、装备、技能、成就、战役、故事、地牢及世界事件。
- 合作模式界面文本、更新日志、动态提示与 Canvas 中的系统文字。
- 中文字体回退、中文断行、菜单说明排版、帮助弹层与中文搜索。

当前共有 10,307 条唯一译文。词典由 34 个对应原英文模块的中文文件，以及 1 个补充文件组成。英文基础词典的 8,861 个唯一键全部具有中文译文。最终数量及验收证据见[验收记录](ACCEPTANCE.zh-CN.md)。这表示词典键覆盖完整，不等于穷举了游戏全部剧情、随机事件和联机分支。

中文使用系统自带 CJK 字体，不依赖外部字体服务。Service Worker 的缓存列表包含全部中文词典；浏览器首次完整加载后可离线使用。项目默认不在 localhost 自动注册 Service Worker，验收脚本会显式注册并验证离线重载。

## 兼容性与边界

玩家输入、地图代码、存档和网络数据保持原值。英雄/档案的输入框、主要姓名展示及 Canvas 名牌已有保护。新创建的默认名字使用中文；已有档案名称不会被批量改写。

少量旧系统日志先把玩家姓名与系统消息拼成整句，再交给自动翻译。如果自定义俄文姓名刚好与系统词条同名，这些旧日志中的显示仍可能被翻译；输入框、主要名牌及保存的数据不受影响。

本次实际浏览器验收使用 Windows Chrome，并模拟桌面、手机竖屏和手机横屏。没有将这些模拟结果宣称为 iOS/Android 真机、Firefox、Safari 或公网多人游戏验收。项目已有测试失败的基线对照单独记录，不能把汉化专项通过理解成整个原项目零缺陷。

## 维护与复验

```powershell
npm run check
npm run test:i18n
npm run audit:zh
npm ci --prefix tools/browsers
node tools/i18n/browser-check.js --play --all
```

浏览器检查使用临时独立档案，不操作日常浏览器的玩家存档。它会检查页面文字与悬停提示中的俄文、按钮文字越界、中文帮助搜索、保存读取、三语切换和离线词典。浏览器脚本会隔离外部统计与公共合作目录请求；因此其结果只用于本地界面验收。

截图、词典覆盖报告和浏览器记录写入 `tests/i18n/out/`，不纳入 Git。`acceptance-manifest.json` 记录被检查的提交、时间和截图 SHA-256；截图与报告应当一起保留。

新增文案时先遵循[术语表](TERMINOLOGY.md)，再修改对应 `js/i18n/zh-CN-*.js`。HTML 标签会切断原句，静态扫描无法识别所有运行时拼接，发现漏译时应补实际渲染用例到 `tests/fixtures/i18n-zh-html.json`。不要用空译文、删除提示或扩大扫描排除项消除错误。

技术起点和范围约定见[最初审计](LOCALIZATION_AUDIT.md)。
