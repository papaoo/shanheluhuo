# 简体中文浏览器版验收记录

日期：2026-11-16。原始代码基线：`b1ec26d2f2eb7ff131a3fad7347bb5199d2090ac`。开发分支：`feat/zh-cn-localization`。

这是本地浏览器版本的实现与验收记录，未发布到线上。最终浏览器检查对应的提交、截图时间和 SHA-256 位于 `tests/i18n/out/acceptance-manifest.json`；复验时应将报告与该清单配套使用。

## 实现结果

独立增加 35 份简体中文词典，共 10,307 条唯一译文，覆盖英文基础词典的 8,861 个唯一键，另补浏览器源文本、更新日志及运行时 HTML 拼接片段。词典覆盖检查同时验证参数占位符、非空译文、冲突译文和俄文残留；完整计数保存在 `catalogue-report.json`。

语言选择优先使用 URL 显式参数，其次使用已保存的语言偏好；默认语言已按用户要求设为简体中文，不再跟随浏览器语言。切换顺序为俄语 → 英语 → 简体中文。新增中文字体、Canvas 测量/绘制一致的字体回退与中文断行、中文帮助搜索。中文帮助弹窗已调整到项目既有弹窗层级，避免被移动端 HUD 覆盖。

剧情、人名、建筑、资源与职业采用统一术语。复核中修正了教程快捷键标签拆句、建筑“造价/停工”歧义、矿物配方、组队奖励、季节“冬季/冬境”歧义等实际问题；相应场景加入回归检查。

没有修改游戏机制、战斗平衡、建筑 ID、存档结构或合作协议。主要姓名显示采用明确保护边界；玩家文本的剩余限制见[使用说明](README.zh-CN.md#兼容性与边界)。

## 验收方法

| 检查 | 命令与证据 |
| --- | --- |
| 脚本装载与语法 | `npm run check`，通过；`npm-check.log` |
| 语言框架与词典 | `npm run test:i18n`：语言选择、缓存隔离、用户文本保护、Canvas、全部词典、实际 HTML 与上下文回归 |
| 源文本审计 | `node tools/i18n/zh-audit.js --source --write tests/i18n/out/catalogue-report.json` |
| 浏览器验收 | `node tools/i18n/browser-check.js --play --all`；`browser-report.json`、截图及清单 |
| 完整原有回归 | `npm test`；`npm-test.log`，结果详见下文 |
| 原始代码对照 | 原始提交的隔离 worktree；`baseline-tests.json`、`baseline-tests.log` |
| 渲染预算 | `npm run test:render` 及 `npm run test:render -- --lang zh-CN`；原始阈值保留，详见下文 |

浏览器尺寸为桌面 1280×800、手机竖屏 390×844、手机横屏 844×390。检查菜单、建图、难度、外观、教程、游戏、建筑、英雄、帮助及成就；覆盖中文输入、保存读取、三语切换和离线重载。移动端另检查招牌正常与缩远视角。长面板的正常滚动区域不作为文字溢出；按钮旁悬出的等级徽标及替换为伪元素图标的辅助文字也单独识别。

初轮截图曾未真正打开移动端英雄/建筑面板，且教程尚未出现；这些样本没有作为通过证据。检查脚本已加入明确的界面可见性等待并重拍。独立视觉审查覆盖最终截图，帮助层级修复另由主代理检查。

所有浏览器测试使用临时独立档案。测试中隔离外部统计脚本与公共合作目录，因此没有验证公网多人联机。Windows Chrome 的移动视口模拟不能替代真机或其他浏览器验证。

## 原有回归失败

完整检查共 104 项：88 项通过，16 项失败，另有 2 项警告。双 seed 模拟、存档往返和确定性检查通过。

- `raid`、`coop-hire`、`campaign-coop`、`campaign-coop-acts`、`coopkit`、`spire`、`coop-restart`、`coop`：客户端测试 VM 加载 `fantasy-published-gallery.js` 时缺少 `URLSearchParams`。基线代表用例复现相同装载错误，8 项日志指向同一根因。
- `profs`、`reaper`、`injury`、`sea`、`abil`、`faceart`、`late`、`regrow`：已在原始提交逐项复现相同玩法/头像断言失败。
- 警告来自 `arena` 的职业胜率分布及 `campaign` 的塌方波测试。

这些结果说明原项目本身并非全套绿色；本轮没有修改断言、跳过失败项或调整玩法来获得通过。

## 渲染与检查边界

原始基线渲染预算也有 2 项超限：普通视角 `36.01 > 25`、缩远视角 `70.91 > 40`；冷帧构建通过。初轮工作区样本同样超过这两个阈值。阈值保持不变，最终提交的实测结果单独留存在日志中，不将机器上的一次波动宣称为性能改善。

静态覆盖率只以明确分类后的浏览器候选文本为分母。开发页面、服务器日志等排除项在 JSON 报告中列明；没有将它们计作“已翻译”。自动检查与代表场景人工复核不能保证穷尽全部随机剧情和状态组合。后续发现漏译，应保留原文与触发路径并新增渲染用例。

## 证据目录

所有本机证据位于 `tests/i18n/out/`（Git 忽略目录）。核心文件为 `catalogue-report.json`、`browser-report.json`、`acceptance-manifest.json`、完整回归日志和基线对照日志。此目录的内容会随复验更新；发布或转交时应另行保存同一次验收的完整副本。
