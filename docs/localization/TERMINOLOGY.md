## 格式约定

- 保留全部 {0}/{1} 等动态参数、HTML 标记、快捷键、数值和图标。
- 中文使用全角标点；数值、倍率、快捷键采用原信息。正式技能名不加多余引号。
- 同一角色/建筑/资源全局统一；专名优先自然音译，说明性生物名优先意译。
- 不把玩家自定义名字、聊天、地图代码或变量 ID 当成待翻译数据。
- 不把未完成翻译替换成空白、英文或通用“提示”来伪造覆盖率。
